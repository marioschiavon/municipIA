# Patch Logs — MunicipIA

Registro das atualizações do MunicipIA, em linguagem simples, para consulta dos clientes.

## Como funciona

- Um arquivo por dia com mudanças, nomeado `AAAA-MM-DD.md`.
- Cada arquivo traz as **Novidades** e **Correções** daquele dia.
- Dias sem mudanças funcionais não geram arquivo.
